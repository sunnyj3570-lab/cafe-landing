# cafe-landing ☕

가상의 동네 카페 **온기 커피**를 소개하는 한 페이지짜리 랜딩 페이지입니다.
프레임워크나 빌드 도구 없이 **HTML과 CSS만으로** 만들어서, 파일을 열기만 하면 바로 볼 수 있습니다.

## 이 폴더는 무엇인가요?

카페·소규모 매장용 랜딩 페이지 예제입니다. 다음과 같은 용도로 쓸 수 있습니다.

- 카페나 매장 홈페이지의 시작 템플릿
- HTML/CSS 레이아웃(그리드, 반응형, sticky 내비게이션) 학습용 예제
- GitHub Pages로 바로 배포해 보는 연습용 정적 사이트

> 카페 이름, 주소, 전화번호, 메뉴 가격은 모두 **예시 값**입니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 내비게이션 | 상단 고정 메뉴 (소개 · 메뉴 · 오시는 길), 클릭하면 해당 섹션으로 부드럽게 스크롤 |
| 히어로 | 배경 이미지 위에 슬로건과 "메뉴 보기" · "오시는 길" 버튼 |
| 소개 | 카페의 특징 3가지 (주 2회 로스팅, 매일 굽는 디저트, 머물고 싶은 공간) |
| 메뉴 | Coffee · Non-Coffee · Dessert 메뉴와 가격 |
| 오시는 길 | 주소, 영업시간, 문의처와 예약 문의 버튼 |
| 푸터 | 저작권 표기 |

## 파일 구조

```
cafe-landing/
├── index.html   # 페이지 구조와 내용
├── style.css    # 색상, 폰트, 레이아웃, 반응형 스타일
└── README.md    # 이 문서
```

## 실행 방법

1. 이 레포를 내려받습니다.
   ```bash
   gh repo clone sunnyj3570-lab/cafe-landing
   ```
2. `index.html`을 브라우저로 엽니다.

배경 사진(Unsplash)과 웹폰트(Google Fonts)는 인터넷에서 불러오므로, 온라인 상태에서 열어야 제대로 보입니다.

## 내 카페에 맞게 바꾸기

- **카페 이름 · 문구 · 메뉴 · 주소**: `index.html`의 텍스트를 수정합니다.
- **색상**: `style.css` 맨 위 `:root`의 색상 변수(`--accent`, `--bg` 등)를 바꾸면 전체 톤이 함께 바뀝니다.
- **배경 사진**: `style.css`의 `.hero` 안 `url(...)` 주소를 원하는 이미지로 교체합니다.

## 사용 기술

- HTML5, CSS3 (CSS Grid, Flexbox, CSS 변수, `clamp()`)
- Google Fonts: Gowun Batang, Noto Sans KR
- 화면 너비 720px 이하에서 모바일 레이아웃으로 전환
